Architecture

Presentation tier
Thymeleaf MVC controllers (browser) and REST controllers (web services consumed by the desktop client)
Business tier
Services, pricing strategies, booking validation chain, notification observers, report generators
Data tier
JPA entities, Spring Data repositories, a JDBC reporting DAO over database views and stored functions, Flyway-managed schema
Distribution
The desktop client is a separate process reaching this server only over HTTP + JSON; it shares no code except the DTO contract
Database features in use
5 reporting views, 2 stored functions, 2 triggers, unique and CHECK constraints, a pessimistic-locked sequence table, optimistic locking
