Why a booking can be refused

Every booking passes through these rules, in this order. The first one that fails is the message you see, so you always get the most fundamental reason rather than a confusing later one.

  1. RULE — the date must be in the future and within 180 days. — the whole appointment must finish before the clinic closes. — appointments start on the hour or the half hour. — the dentist must be practising and on shift. — the dentist must not already be booked at that time. — the patient must not already be booked elsewhere then.

This list is read from the running system, not typed into this page, so it is always the rules actually in force.

How bills are priced

Every treatment names one of these rules. You never type an amount — the system reads the dentist's consultation fee and the treatment price.

KEY
Name
Description
  • Concessions — senior citizens (65 and over) receive 10% and children (under 18) receive 5% on clinically necessary treatment. These are applied automatically from the patient's date of birth. Cosmetic treatment is excluded.
  • Discounts do not stack — the larger of the automatic concession and any approved manual discount applies, capped at 50%.

Still stuck?

Telephone the clinic on phone and ask for the practice manager. If the system itself is misbehaving, note what you were doing at the time — the administrator can find the matching entry in the audit trail.
